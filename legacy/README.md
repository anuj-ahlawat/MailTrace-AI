# Archived prototype source

The previous Flask backend, mock data, seed scripts, and unregistered FastAPI modules are retained here for reference. They are not imported, served, copied into Docker images, or used by the production UI. Do not run these entry points against the new database.

The supported entry points are `backend/app/main.py` and `app/`. The new database defaults to `mailtrace_enterprise`, leaving the prototype's `mailtrace_ai` database untouched. Existing raw originals were not preserved by the prototype, so legacy evidence cannot be relabeled as verified evidence; reacquire original files through the supported ingestion pipeline.
